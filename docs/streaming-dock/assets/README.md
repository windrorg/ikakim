## C / P / O / V の読み方

| 区分 | 意味 |
| --- | --- |
| C | 確定した要求・方針。希望機能も含むため、必須か希望かは本文で確認する。実装完了や性能保証を意味しない。 |
| P | 設計提案・暫定値。実証や協議を通じて採否・条件を決める。 |
| O | 未決定。仕様値や採用範囲を今後決める。 |
| V | 実機検証待ち。対象基板、OS、端末、接続と負荷をそろえて確認する。 |

Linuxでmix／FXを行う方針と、FXの採用範囲・音声バスの実装・遅延の保証は区別します。端末充電とHDMIパススルーは希望機能です。最新の到達点は[実装状況と検証の記録](../implementation-status.md)を参照してください。
